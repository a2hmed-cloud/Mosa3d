Tablet test — bookmarklet

Copy this code into a new browser bookmark's URL field. Then open the Minecraft tab and tap that bookmark. It attempts to load the test bridge in the current page.

  1. On the tablet, create a bookmark with any name, e.g. BlockLink Test.
  2. Edit that bookmark and replace its address with the copied code.
  3. Open the original Minecraft page, then activate the bookmark.
  4. If the overlay appears, try W/A/S/D and Jump. Tell me what works.
Important: This is only a same-page input experiment. It is not connected to the phone yet. If the school browser blocks bookmarklets or the game ignores synthetic events, we will know that before building the remote connection.
BlockLink is an independent browser experiment. It does not host or replace the original game.
