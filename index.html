BLOCKLINK

One world.
Two screens.

A browser-only remote controller experiment for the Minecraft page you already play. The tablet stays on the original game; the phone becomes the controller.

Prototype setup — connection not active yet
01 / TABLET

Game bridge

A tiny script must run in the same page as the game so it can translate remote commands into game input. This is the first compatibility test.

02 / PHONE

Touch controller

A responsive joystick and action buttons send movement, jump, attack, place, and camera commands from the second device.

03 / LINK

Live connection

After the same-page input test succeeds, we add a secure room-based connection between the two browser tabs.

Important: A normal website cannot inject keyboard or mouse input into another website's tab. The tablet bridge has to execute inside the game page. This prototype does not claim that remote control is working yet.
BlockLink is an independent browser experiment. It does not modify or host the original game.
